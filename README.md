# 🛰️ Disaster Alert AI

This project is a smart AI-based Disaster Safety Helper created using AI Studio prompt engineering.

## 🌍 Features:
- Detects disaster type (earthquake, flood, fire, storm)
- Gives safety instructions
- Provides emergency steps
- Suggests emergency kit
- Calm and supportive responses

## 🧠 Tech Used:
- Google AI Studio (Prompt Engineering)

## 🎯 Purpose:
To help people stay safe during natural disasters using AI guidance.
